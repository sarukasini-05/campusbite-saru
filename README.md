# CampusBite 🍴

A colourful, responsive **frontend-only food ordering interface** designed for campus life.

## ✨ Features

- Responsive desktop/tablet/mobile UI
- Food categories and filtering
- Live food search
- Food cards with ratings and descriptions
- Functional shopping cart
- Quantity controls and automatic totals
- Favourite/save functionality
- Checkout modal with basic validation
- Mock order confirmation
- Toast notifications
- Dark/light mode with localStorage
- Smooth hover and entrance animations
- Accessible labels and responsive navigation

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## ▶️ Run Locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

## 🌐 GitHub Pages

This project is static and can be deployed directly with GitHub Pages.

Go to **Repository → Settings → Pages** and select:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

## 🎯 Why CampusBite?

CampusBite focuses on a realistic student problem: discovering affordable food quickly during short breaks. The interface demonstrates frontend fundamentals such as DOM manipulation, arrays/objects, filtering, event listeners, state management, localStorage and responsive CSS.
